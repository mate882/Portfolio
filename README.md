# Personal developer portfolio

A framework-free personal portfolio built with HTML, CSS, vanilla JavaScript, and GSAP.

## Run locally

Open `index.html` in a browser, or serve this folder with any static local server.

## Personalize it

- Update your name, email, and social links in `js/projects.js` (`portfolioConfig`).
- Replace the four project titles, text, and demo/GitHub URLs in the `projects` array in `js/projects.js`.
- Replace the abstract preview markup in `js/main.js` with real screenshots when available. Put optimized images in `assets/images/` and add `loading="lazy"` to project-card images.
- Update the title, metadata, and footer name in `index.html`.

The project modal is data-driven, so every future completed project can use the same detail structure. Keep the in-progress neural-network project out of the array until it is finished and demonstrable.
